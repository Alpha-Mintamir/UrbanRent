## 📦 Installation

1. **Download/Clone the files**
   ```bash
   git clone [repository-url]
   cd yegna-landing
   ```

2. **Add your images** (optional - fallbacks provided)
   - logo.png
   - s1.jpg through s6.jpg (app screenshots)

3. **Add Google Maps API Key** (optional - fallback map provided)
   - Open `index.html`
   - Replace `YOUR_API_KEY` on line 10 with your actual API key
   - Get a key at: https://console.cloud.google.com/

4. **Open in browser**
   ```bash
   open index.html
   ```
   or just double-click the file!
