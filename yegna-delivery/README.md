## 🚀 Getting Started

1. **Add Google Maps API Key**:
   - Replace `YOUR_API_KEY` in `index.html` with your actual Google Maps API key
   - Get one from: https://console.cloud.google.com/

2. **Add Images (Optional)**:
   - Add `logo.png` for the company logo
   - Add `s1.jpg` through `s6.jpg` for app screenshots
   - The website works perfectly without images (fallbacks included)

3. **Open the Website**:
   - Simply open `index.html` in a modern web browser
   - Works best in Chrome, Firefox, Safari, or Edge
